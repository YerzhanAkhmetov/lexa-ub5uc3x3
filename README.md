# 👊 Догони Леху

Браузерная игра: Леха бегает по офису и кричит «Помогите!», а ты гоняешься за ним кулаком.

## ▶️ Играть

**https://yerzhanakhmetov.github.io/lexa-ub5uc3x3/**

## 📌 Правила

- Есть **20 секунд**.
- Кликай по Лехе — каждый удар засчитывается, Леха вскрикивает и отскакивает.
- Попал **больше 10 раз** — победа: «Ты побил Леху!», Леха плачет.
- Не успел — Леха танцует.

## 🎵 Звук

Вся музыка и звуки создаются браузером (Web Audio), файлов не нужно.
Голос «Помогите!» — встроенный синтезатор речи браузера, звучит по-разному в Chrome, Safari и Firefox.

Своя музыка: положите `music.mp3` рядом с `index.html` — во время погони будет играть он.

## 🗂️ Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся игра: разметка, стили, код |
| `leha.png` | фото Лехи |
| `music.mp3` | необязательная фоновая музыка |

## 💻 Запустить у себя

Открыть `index.html` в браузере — сервер не нужен.
