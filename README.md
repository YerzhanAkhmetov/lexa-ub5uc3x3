# 👊 Догони Лёху

Браузерная игра с тремя уровнями: Лёха убегает сначала по закатной парковке, затем по ночной и наконец по марсианской. Его Лексус каким-то образом добирается до Марса вместе с ним.

## ▶️ Играть

**https://yerzhanakhmetov.github.io/lexa-ub5uc3x3/**

## 📌 Правила

- В каждом уровне есть **20 секунд**. На каждом следующем Лёха бегает быстрее.
- Кликай по Лёхе — каждый удар засчитывается, Лёха говорит «Ай!» или «Больно!», отскакивает и видит звёздочки.
- Попал **11 раз** — сразу переходишь к следующему уровню. Пройди все три — «Лёха сдался!», Лёха плачет.
- Не успел набрать 11 попаданий в раунде — Лёха танцует, а игра начинается заново.
- На парковке стоит Лексус Лёхи: наведи на него — в руке бита. Удар по машине — трещины, тихая сигналка,
  а Лёха кричит «О нет, мой Лексус!». На победу удары по машине не влияют.

## 🎵 Звук

Фоновая мультяшная мелодия и тихий звук удара по Лексусу создаются браузером (Web Audio). Звук можно выключить кнопкой ♪ вверху экрана.
Реплики Лёхи записаны в `sounds/` мужской русской моделью Piper Dmitri и одинаково звучат в разных браузерах.

Своя музыка: положите `music.mp3` рядом с `index.html` — во время погони будет играть он.

## 🗂️ Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся игра: разметка, стили, код |
| `leha.png` | исходное фото Лёхи |
| `leha-head.png` | портрет Лёхи с прозрачным фоном для персонажа |
| `lexus.png` | исходное фото машины |
| `lexus-cutout.png` | машина с прозрачным фоном для сцены |
| `sounds/*.wav` | готовые реплики Лёхи |
| `music.mp3` | необязательная фоновая музыка |

## 💻 Запустить у себя

Открыть `index.html` в браузере — сервер и сборка не нужны. Файлы также можно целиком разместить на GitHub Pages.
