# Реплики Лёхи

Готовые WAV-файлы для игры; браузер воспроизводит их без синтезатора речи и без сети после загрузки страницы.

| Файл | Реплика |
|---|---|
| `help.wav` | «Помогите!» |
| `ay.wav` | «Ай!» |
| `bolno.wav` | «Больно!» |
| `oy.wav` | «Ой!» |
| `lexus.wav` | «О нет! Мой Лексус!» |

Созданы локально с Piper 1.8.0 и моделью [ru_RU-dmitri-medium](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/dmitri/medium) (лицензия репозитория модели MIT, исходный датасет CC0). Настройки синтеза: `length_scale=0.92`, `noise_scale=0.6`. После синтеза применены мягкий фильтр высоких частот, короткие плавные вход и выход и снижение уровня до 87%.
